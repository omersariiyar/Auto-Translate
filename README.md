# Auto-Translate & Auto Reverse Ə

🌍 **Gerçek zamanlı çeviri ve Azerbaycan Türkçesi düzeltme araçları** | Real-time translation and Azerbaijani Turkish correction tools

---

## 📚 Dökümantasyon | Documentation

Bu proje iki ana araca sahiptir | This project contains two main tools:

### 🔹 Auto Translate
Yazdığınız metni anında çeviren güçlü bir araç  
A powerful tool that instantly translates your text as you type

- 🇬🇧 [English README](README_EN_auto_translate.md)

### 🔹 Auto Reverse Ə
Türkçe metinleri otomatik olarak Azerbaycan Türkçesi'ne dönüştüren akıllı düzeltme aracı  
Smart correction tool that automatically converts Turkish text to Azerbaijani Turkish

**📖 Detaylı Dökümantasyon:**
- 🇹🇷 [Türkçe README](README_TR_auto_reverse_e.md)
- 🇬🇧 [English README](README_EN_auto_reverse_e.md)

## 🚀 Hızlı Başlangıç | Quick Start

### Kurulum | Installation
```bash
pip install deep-translator pynput pyperclip
```

### Çalıştırma | Run
```bash
# Auto Translate
python auto_translate.py

# Auto Reverse Ə
python auto_reverse_e.py
```

**Veya Batch Dosyaları ile | Or with Batch Files:**
- `auto_translate.bat` - Çeviri aracını başlatır | Starts translation tool
- `auto_ə.bat` - Azerbaycan düzeltme aracını başlatır | Starts Azerbaijani correction tool

## ✨ Özellikler | Features

### Auto Translate
- ✅ Herhangi bir uygulamada çeviri | Translation in any application
- ✅ 100+ dil desteği | Support for 100+ languages
- ✅ Otomatik dil algılama | Automatic language detection
- ✅ Noktalama koruması | Punctuation preservation

### Auto Reverse Ə
- ✅ 2500+ kelime eşleşmesi | 626+ word mappings
- ✅ Türkçe → Azerbaycan Türkçesi | Turkish → Azerbaijani Turkish
- ✅ `Ctrl + Sol Shift` ile manuel ə ekleme | Manual ə insertion with `Ctrl + Left Shift`
- ✅ JSON tabanlı sözlük | JSON-based dictionary
